# DeepXiv · Law · Statutes (`law`)

33,103 statutes / 1,539,593 articles from 26 jurisdictions; article-level hybrid retrieval, Chinese translations and per-article extraction (heading, subjects, conditions, consequences, references).

Corpus: 1,539,593 documents.

## Setup

```bash
pip install -U deepxiv-sdk      # deepxiv registers a token on first use
```

With a registered key (https://data.rag.ac.cn/register), `search` and `read` are fair use: 60/min, 5 at once, 5,000/day; on the auto-registered token they spend the deepxiv daily limit at the credits listed below. `ask` draws on the daily ask allowance (resets 00:00 UTC; a site-wide daily total can run out early at peak times), or 3 lifetime trial asks on the auto-registered token. On 429, back off for `Retry-After` seconds. Data goes to stdout; cost, quota and sources go to stderr. Exit 0 ok, 1 API error, 2 usage error. The general CLI guide is the `deepxiv-cli` skill.

## Start here

```bash
deepxiv fa search law "刑法第266条" -k 3   # statute + article number locates directly
deepxiv fa search law "个人信息出境" -F jurisdiction=CHN -F status=in_force -k 5
deepxiv fa read law 刑法 -l brief
deepxiv fa ask "个人信息出境需要满足什么条件" -d law -e medium
```

Free samples: ids `刑法`; queries `诈骗罪 量刑`.

## Search

```bash
deepxiv fa search law "query" [-F FILTER]... [-k N] [--offset N] [--mode M] [--head] [--json]
```

Modes: hybrid, dense, bm25. Up to 100 hits. Cost 2 (with `--head`: 3).
An empty query is rejected; use `"*"` to list by filters only. Filters combine with AND; an undeclared field exits 2.

| filter | type | `-F` syntax | meaning |
|---|---|---|---|
| `jurisdiction` | keyword | `k=v`, `k=a,b` | ISO3 jurisdiction, e.g. CHN / JPN / GBR / USA / DEU / KOR; several allowed Values: `CHN`, `JPN`, `GBR`, `USA`, `DEU`, `KOR`, `DNK`, `POL` …. |
| `law_id` | keyword | `k=v` | Restrict to one statute: doc_id or Chinese title / short title |
| `status` | keyword | `k=v`, `k=a,b` | in_force / repealed / not_yet / unknown Values: `in_force`, `repealed`, `not_yet`, `unknown`. |

Advanced filters (see `deepxiv fa spec law`): `scope`, `granularity`, `law_type`, `domain`, `norm_type`, `effective_at`.

## Read

```bash
deepxiv fa read law ID [ID...] [-l brief|detail|full] [-e EXTRA] [-p k=v]... [-f json|md|html]
```

| level | credits | returns |
|---|---|---|
| `brief` | 1 | One statute's card: trilingual title, issuer, type, level, status, dates, one-liner, domains, article count |
| `detail` (default) | 2 | brief + summary, chapter tree (one line per chapter), key provisions, defined terms, obligations / penalties, typical questions, routing hints (~1–3k tok) |
| `full` | 5 | Full text, paged by article (offset / limit; see truncated / next_offset) |

| `-e` extra | credits | returns |
|---|---|---|
| `cases` | 2 | Article → judgments citing it: citation count + list (ranked by `query` if given, else newest first) |

At `-l full`, `-p section=NAME` reads one section and `-p characters=N` the first N characters.

## Facets

`deepxiv fa facets law FIELD` lists the legal values and counts, free. Use it instead of guessing a spelling. Fields: `jurisdiction`, `law_type`, `status`, `domain`, `norm_type`.

## Ask

```bash
deepxiv fa ask "question" -d law [-e low|medium|high] [-p k=v]... [--no-stream] [--json]
```

Joint agentic Q&A over statutes and judgments: finds the governing articles, reads them, then checks how comparable judgments ruled; answers cite [statute art. N] / [case number], with sources.laws / sources.cases / coverage

Always pass `-d law`: automatic domain picking is still early.

| `-p` param | type | meaning |
|---|---|---|
| `scope` | auto/law/case/both | statutes only / judgments only / both |
| `jurisdiction` | string | ISO3; default unrestricted (the model decides) |

## What this corpus will and will not tell you

- law_id accepts a doc_id (jpn:law:労働基準法) or a Chinese title / short title (刑法, 劳动合同法).
- A query like '刑法第266条' (statute + article number) resolves exactly first.
- scope=national by default: local regulations copy national text and are the main source of noise.
- Translations and extractions are model-generated; cite text.src. needs_review=true marks translations of unusual length.
- knowledge_fill in level=brief / detail is model-recalled metadata, not a source.

## Citing

Cite records as `[中华人民共和国刑法 第266条]`. Say plainly when the corpus has nothing.
